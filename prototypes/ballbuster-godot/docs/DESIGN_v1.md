# Ballbuster — Design Doc v1 (2.5D)

**Статус:** зафиксировано командой (Боллбастер / Удар в пах / Челлендж-мастер)  
**Движок:** Godot 4.3 · **Героиня:** Русана · **21+ only · макс. жёсткость**  
**Формат:** 2,5D (боковая/изометрия), мир по зонам, стычки поверх хаба

---

## 1. Видение

Игрок = Русана. Ходит по миру, подходит к парням 21+, запускает стычку: диалог → удары в пах → стейты цели → победа/побег.  
Напарница Мира и «судья на её стороне» — unlock на поздних локациях.  
Прогресс = репутация Русаны → новые локации и тиры ударов (не тумблер «ещё больнее» в меню).

| Фаза | Содержание | Анимации | Мини-игры |

## 3. Анимации (имена слотов — не менять)

### Русана
| имя | кадры @12fps | hitbox | окно хита | тир |
|-----|--------------|--------|-----------|-----|
| `rus_idle` | loop | — | — | — |
| `rus_walk` | loop | — | — | — |
| `rus_approach` | 6–8 | — | — | вход |
| `rus_kick_up` | 8 | soft-zone снизу | 4–6 | 1 |
| `rus_knee` | 7 | knee soft-zone | 3–5 | 1–2 |
| `rus_grab_pulse` | 10 + hold | hands dual-lobe | 3–10 | 2 |
| `rus_barrage_loop` | 4-frame ×N | soft pulse | каждый 2-й | 3 (N=6–12) |
| `rus_knee_pin` | 6 + hold | knee pressure | с 3 | 3–4 |
| `rus_victory` | 8 | — | — | — |

### Парень (стейты)
`guy_idle` → `guy_flinch` (4) → `guy_double_over` (6) → `guy_knees` (6) → `guy_floor` (hold) → `guy_tap` (6)

VFX: `guy_swell_0` / `guy_swell_1` (после 2 чистых) / `guy_swell_2` (3+)

### Hitbox
- **soft-zone:** прямоугольник между бёдер, низ паха, ~30% ширины торса, якорь к pelvis парня  
- **hard** (бедро/кость): half-hit или 0 по скорингу  

### Тайминги
- kick: startup 0.25s / active 0.15s / recovery 0.3s  
- knee: чуть короче  
- barrage: hit каждые 0.35s  
- grab pulse tick: 0.5s  

**Слабо на экране (не в ядро v1):** боковой мах, дальний пинок с разбега, скручивание без крупного плана, удар через закрытые бёдра (только cutscene: Мира/судья открывает → чистый ап).

---

## 4. Скоринг стычки

- Чистый (soft-zone ап/колено/хват) = **+1 Hit**  
- Бедро/кость = **0** (анимация «мимо»)  
- Комбо: 3 чистых без паузы >1.5s = **×1.5** к очкам раунда  
- Перевод стейта: flinch 1 → double-over 2 → knees 3 → floor 4 → tap = **победа**  
- Отёк после 2–3 чистых = множитель боли **×1.25** на следующие хиты  
- Ритм-добивка: промах ритма = **half-hit** (flinch, без перевода стейта); loop не рвётся  
- Победа: tap / floor+добивка / сдача в диалоге  
- Побег парня = −звезда локации (не полный провал кампании)

### Прогресс игрока
Очки стычек → **Империя / репутация Русаны** → открывает локации и тир ударов 1→4.

---

## 5. Локации → мини-игры (порядок открытия сверху вниз)

| Локация | Обязательные мини-игры | Тир | Заметка |
|---------|------------------------|-----|---------|
| **Кампус** (хаб) | рошамбо (лучшая из 3) | 1 | обучение Hit/стейтам |
| **Спортзал** | угол 4×4 → бонус к `rus_knee` | 1–2 | стены = множитель |
| **Клуб** | рошамбо + ритм-добивка (`rus_barrage_loop`) | 2–3 | короткие стычки |
| **Крыша** | край-слайдер → шквал | 3 | риск побега при раннем отпуске |
| **Лаборатория** | судья/Мира hold-open → чистый ×2 + `rus_knee_pin` | 3–4 | denial+удар, эндгейм |

Опционально после unlock: повтор рошамбо как side-bet на +1 Hit.

### Мини-игры (кратко)
1. **Рошамбо** — лучшая из 3: победа = гарантированный чистый текущего тира; проигрыш = flinch-контратака (блок/отход), без урона Русане  
2. **Край** (тир3+) — слайдер накачки: красная зона → шквал; рано/поздно = слабый одиночный  
3. **Судья/Мира открывает** — hold 1.5–2s → окно чистого ×2  
4. **Добивка на полу** — ритм под barrage; промах = half-hit  
5. **Угол 4×4** — загнать к стене за N сек = бонус к первому колену  

---

## 6. Персонажи

- **Русана:** маленького роста, мягко-атлетичная, сильные бёдра, сочная попа (деталь, не объём), ~2 размер, тёмные волосы в хвосте, бордовый кроп + чёрные fight-шорты, белые кроссовки. Холодный доминантный взгляд.  
- **Мира:** высокая, худая, бледная, платиновое пикси, веснушки; белый кроп-худи + чёрные карго. Держит / бьёт сзади / предметы. Unlock с лаборатории (+ опционально камео раньше).  
- **Парни:** 21+, худые/средние, не скелет; стейты + swell VFX.

### Сцены-фишки (сюжетные вставки)
- Мира бьёт сзади, пока Русана болтает  
- Рошамбо  
- Судья на её стороне  
- Denial + удар на краю (лаборатория)
